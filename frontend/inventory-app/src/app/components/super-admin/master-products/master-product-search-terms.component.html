Supplier search terms

Use these when a supplier names this product differently. Each search phrase is a separate search, tried in order: the second phrase is searched only when the first finds nothing, or finds nothing that is this product. Flavour aliases are other words the supplier uses for this product's flavour (for example Plain for Original). They are only used to recognise the product in results, never as search words, and the brand, type and size must still match. An entry for one supplier replaces the entry for its connector. Products without an entry are searched as before.
